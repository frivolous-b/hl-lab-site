# hl-lab-site

The public showcase of a small research lab for Hyperliquid strategies:
what it does, the validation gate every idea must pass, the append-only
hypothesis ledger with its verdicts, the results, and a live card for the
paper run (testnet, no real money). Site: https://frivolous-b.github.io/hl-lab-site/

This repository only holds generated output. The source lab is private;
the `gh-pages` branch is rebuilt from it by a GitHub Action on every push,
and the build refuses to publish anything private (addresses, keys, ids,
tokens, followed wallets, local paths). Nothing here is investment advice.
